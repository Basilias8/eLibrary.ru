# 📚 eLibrary Scientific Paper Parser (React + Express)

Веб-приложение для парсинга и каталогизации научных статей с платформы **eLibrary.ru**. Переписано на современный стек: React 18, Vite, TypeScript, Tailwind CSS и Express.

## 🚀 Основные возможности

- **Парсинг статей по URL**: извлечение названия статьи, списка авторов (формат: `Фамилия И.О.`), года издания, типа работы, количества страниц и места издания.
- **Проверка на дубликаты**: защита от повторного сохранения статьи с одинаковым URL.
- **Интерактивный каталог**: список последних обработанных статей с быстрым просмотром детальной карточки.
- **Детальный просмотр статьи**: таблица библиографических параметров, список авторов, прямая ссылка на eLibrary.ru.
- **Быстрые примеры**: кнопки для мгновенной загрузки и проверки демонстрационных научных публикаций.
- **Ручной ввод HTML**: поддержка вставки фрагментов разметки на случай блокировок или капчи (Тест Тьюринга) со стороны внешнего ресурса.

## 🛠️ Стек технологий

- **Фронтенд**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Бэкенд**: Express, Cheerio, Axios
- **Запуск**: `npm run dev` (порт 3000)
