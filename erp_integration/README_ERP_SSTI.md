# Руководство по интеграции парсера eLibrary в систему https://erp.ssti.ru/

## 1. Анализ сайта https://erp.ssti.ru/
- **Платформа**: Корпоративный портал / ERP Северского технологического института (филиал НИЯУ МИФИ).
- **Стек сайта**: Django (Python), сессионная авторизация через `/accounts/login/?next=/`, CSRF-токены, Tailwind CSS, FontAwesome.
- **Целевое назначение**: Учет научно-педагогической деятельности сотрудников (публикации, статьи ВАК/РИНЦ/Scopus, показатели эффективного контракта, отчеты кафедр).

---

## 2. Что требуется для импорта в erp.ssti.ru

Для учета публикаций в научной деятельности вуза требуются следующие обязательные поля:
1. **Название публикации** (Title)
2. **Список авторов** с выделением штатных сотрудников СТИ НИЯУ МИФИ
3. **Журнал / Сборник трудов** (название, том, номер, выпуск)
4. **Год издания и страницы** (диапазон и количество)
5. **Наукометрические идентификаторы**:
   - `DOI` (международный цифровой идентификатор)
   - `EDN` (eLibrary Document Number — стандарт в РФ)
   - `ISSN / ISBN`
   - `УДК` и `ГРНТИ`
6. **Категории индексации (критично для стимулирующих надбавок)**:
   - ВАК (Перечень рецензируемых научных изданий)
   - РИНЦ / Ядро РИНЦ (Russian Science Citation Index)
   - Scopus / Web of Science
   - Белый список научных изданий РФ
7. **ГОСТ Р 7.0.100-2018**: Готовое библиографическое описание для отчетов кафедр.

## 3. Варианты интеграции

### Вариант 1: REST API (Рекомендуемый)
Парсер запускается как отдельный микросервис (на сервере института или в Docker):
- Endpoint: `POST /api/parse` с телом `{"url": "https://www.elibrary.ru/item.asp?id=..."}`
- В интерфейсе создания публикации на `erp.ssti.ru` добавляется кнопка **«Заполнить по eLibrary»**:
  пользователь вводит ссылку, JavaScript отправляет AJAX-запрос, и форма моментально заполняется всеми полями.

### Вариант 2: Встраивание Python-модуля напрямую в Django ERP
Файлы из каталога `erp_integration/`:
1. Скопируйте `ssti_erp_client.py` в приложение публикаций проекта `erp.ssti.ru`.
2. Подключите модель и AJAX-обработчик из `django_models_and_views.py`.
3. Зарегистрируйте url в `urls.py`:
   ```python
   path('publications/autofill/', views.parse_and_autofill_ajax, name='autofill_publication'),
   ```

### Вариант 3: Пакетный экспорт в 1С / CSV / JSON
Если на `erp.ssti.ru` уже есть импорт табличных частей или интеграция с 1С:Университет:
- В данном веб-приложении нажмите **«Экспорт в CSV»** или **«Экспорт в JSON»** — структура сформирована в соответствии с полями вузовской отчетности.

## 4. Решение проблемы с защитой eLibrary.ru (капча / Тест Тьюринга)
eLibrary.ru часто блокирует запросы из облачных дата-центров. Для 100% надежности в парсере предусмотрены:
1. **Режим прямого извлечения по ID/EDN** с встроенными алгоритмами нормализации.
2. **Вставка исходного HTML вручную**: преподаватель может открыть страницу в браузере, скопировать исходный код и спарсить без ограничений.
3. **Пакетная обработка**: парсинг списков статей автора.
